# Security Policy

Nao abra issue publica com chaves, tokens, IPs privados, mundos ou dados de jogadores.
Use o recurso privado **Report a vulnerability** do GitHub deste repositorio.

Arquivos `.mcpack` e `.mcaddon` devem ser tratados como entrada nao confiavel. A presenca
no catalogo nao elimina a necessidade de backup, validacao na versao alvo e teste de gameplay.
